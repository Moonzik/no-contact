!先看这个：个体户 ≠ 什么都能做

最容易栽的地方：以为办了个体户就能做「情感咨询 / 心理咨询」。
不行。微信（和主流平台）对心理咨询类目的准入是硬门槛：
  • 营业执照经营范围必须明确写着「心理咨询」或「健康咨询」
  • 需要 3 位持证咨询师的资格认证（国家心理咨询师证 / 中级以上精神卫生职称 / 心理学中级以上职称，三选一）
  • 还需要这 3 人的合作协议或劳动合同
你没有这些，换了个体户也过不了。而且「婚恋挽回、恋爱教学」这类内容在多个平台是被明确禁止经营的。
NOEX 的正确定位：工具，不是咨询。
你实际做的本来就是「记录 + 打卡 + 陪伴聊天」，不是给人做心理咨询。所以：
  • 服务类目选 工具 → 效率，最稳
  • 名称、简介、版本描述里不要出现「咨询 / 疏导 / 疗愈 / 治愈 / 抑郁 / 焦虑症」
  • 统一用「记录 / 陪伴 / 撑住 / 说说话」这类词
已经有真实翻车案例：有人做「情绪陪伴」小程序，功能没问题， 就因为在名称和描述里用了「心理咨询」这个词，被系统判定为「可能涉及医疗行为」，半年内被处罚两次、最后封号。 这类误判是机器扫关键词触发的，跟你的实际功能无关，所以宁可这个词一次都别出现。

2主体变更：一个好消息，一个要留意的点

好消息：不用重做。
我之前跟你说过「个人主体不能变更为企业」——这个说法是错的，我更正一下。
官方的限制原文是「目标主体不支持为个人类型」，也就是说： 禁止的是「变成个人」，没禁止「从个人变出去」。个人 → 个体工商户是支持的。
项结论
AppID不变。代码一行都不用改
小程序名称保留「断联日记 NOEX」
用户 / 数据 / 代码全部保留
审核费300 元，无论成败不退
公证因为原主体是个人，不能用法人扫脸，必须办公证书（约 300-500 元）
微信认证变更后需重新认证，300 元/年
周期材料齐的话 1-3 个工作日；公证是主要耗时点
要留意的点：备案得重做。
官方备案规则明确写了：主体变更 = 统一社会信用代码变了， 不支持直接改备案，要先注销原备案、再用新主体重新申请。
这意味着中间有一段时间备案是「空」的，而未备案的小程序会被下架。 所以顺序上建议：先把新主体的备案材料准备好，变更一通过立刻提交新备案，别拖。
操作入口：mp 后台 → 设置 → 基本设置 → 主体信息 → 小程序主体变更
个体户执照上的经营者姓名必须和你本人一致，否则会被驳回。

3变更后，后台这三件事必须做

  1. 重选服务类目 —— 变更后原类目会失效，要用新执照重新提交。
    推荐：工具 → 效率　备选：生活服务 → 其他
    别选这些：商业服务-心理咨询（要 3 个咨询师证）、 社交-社区/论坛、社交-笔记（都要增值电信业务经营许可证）。
  2. 更新隐私指引里的主体信息 —— 主体名称和证件号都变了， 隐私指引要跟着更新并重新过审，否则隐私接口会失效（表现就是头像点不动）。
  3. 重新提审一次 —— 主体变了，平台会重新审核。 用下面这份版本描述。

4新版本描述（直接复制）

上传时的「项目备注」填这个，审核员会看：

断联日记 NOEX —— 分手断联期的自我记录与陪伴工具

【功能说明】
1. 今天：记录断联天数、每日一句、打卡与日记
2. 小白：白狐狸形象的陪伴者，4 种性格可选，像普通朋友一样聊天
3. 影子：粘贴微信聊天记录后模仿对方语气，陪你把没说完的话说完
4. 留白瓶：写下想说但不会发出去的话存起来，永远不会被发送
5. 我：微信头像+昵称登录、关于、隐私保护指引、公益求助渠道

【本版更新】
- 支持微信一键填写手机号
- 完善隐私授权流程
- 优化对话贴合度与聊天界面布局

【体验说明】
- 无需登录即可体验全部主要功能（今天 / 小白 / 影子 / 留白瓶浏览）
- 仅「往留白瓶写字」「个人资料」需要微信头像昵称授权
- 所有数据仅保存在用户手机本地，不上传服务器
- 本产品为自我记录与陪伴工具，不提供心理咨询或医疗服务，不替代专业心理治疗
- 不涉及任何付费、交易、社交匹配功能
最后两行别删。「不提供心理咨询」是主动撇清，能规避机器误判； 「不涉及付费」能加快过审——你还没开支付，如实说最快。 这不是永久承诺，以后真加了付费，改版本描述重新提审即可。

5顺带说一句变现

个体户把付费这条路打开了，但现在别急着上：

路现在能做吗
流量主（广告） 能做，个人主体也能开，跟这次变更无关。 门槛是累计 UV 达标（官方口径 1000，以后台提示为准）
mp 后台 → 推广 → 流量主
微信支付 技术上可以了（需开商户号 + 绑定）。 但注意 iOS 端小程序内不能卖虚拟商品（苹果规定）， 会员类虚拟商品在 iPhone 上受限——这要算进你的付费设计里
建议节奏：先把变更和备案走完 → 上线稳定跑一两周 → 攒够 UV 开流量主 → 真想做付费再设计付费点（到时候跟我说，我加代码）。 现在堆付费功能，既拖慢上线又增加审核风险。
