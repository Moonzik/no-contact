一、小白：聊什么接什么

之前小白不智能的根因不只是 AI 提示词——本地规则引擎本身就没有"话题"这个概念。 只有「想念 / 想联系 / 难过 / 失眠…」这几个情绪意图，其余全部落进一句泛泛的兜底话。 所以你聊加班、聊晚饭、聊猫，得到的还是「慢慢说，不着急」这种哪儿都能用的句子。

现在中间加了一层日常话题识别，覆盖最常见的 11 类：

话题你会这么说小白会这样接（温柔档）
吃饭晚饭吃什么 / 好饿 / 点了外卖晚饭打算吃什么？别又随便对付一口。
工作加班 / 老板 / 开会 / 想辞职别把公司的火带回家，下班那一刻起时间就是你的。
学习考试 / 论文 / 考研 / 作业学到这个点，脑子要休息的，先睡，明天再战。
犯困好困 / 起不来 / 赖床困就去睡，别撑着。我又不会跑。
剧/歌/游戏追剧 / 听歌 / 打游戏 / 刷到看到哪了？有没有哪个情节把你气到了。
出门散步 / 堵车 / 地铁 / 旅行到家了吗？路上累不累。
猫狗猫 / 狗 / 主子 / 毛孩子它今天干了什么？给我讲讲。
身体头疼 / 感冒 / 生理期 / 去医院不舒服就别硬撑，该吃药吃药，该躺就躺。
亲友朋友 / 爸妈 / 室友 / 聚会朋友约你就去吧，别总一个人待着。
钱房租 / 购物车 / 快递 / 打折钱的事慢慢来，别一下把自己压太紧。
天气下雨 / 好冷 / 降温 / 出太阳降温了，别忘了加件衣服。

每个话题都配了温柔 / 毒舌两套，毒舌档照样毒，但不提前任：

改前
你：今天加班到十点，好累
小白：嗯，我在听。你说的这些，比反复想 TA 有意义多了。
改后
你：今天加班到十点，好累
小白：别把公司的火带回家，下班那一刻起时间就是你的。今天辛苦你了，累了就歇会儿。

顺手修掉的两个毛病

  • 撒娇人格的尾巴以前通篇是「不许再提 TA」「TA 不会回的，我会」——聊晚饭也被拽回去。现在也分两档：只有聊到断联/情绪才用那池，日常改成黏人爱吃醋但不提 TA。
  • 同一句说两遍：主句池和尾巴池有交集，会抽到一模一样的一句（"我不催你，但你最好别在这儿耗一晚上"出现过两次）。加了去重重摇，实测重复率从可感知降到 0.3%。

二、影子：聊天记录「复制文字」而不是「选文件」

先说一句实话：微信不允许任何小程序直接读取你的聊天记录，所以不存在「点一下自动导入聊天」这种按钮。 能做到的最快路径就是——你在微信里复制，回到这里粘贴。这次把这条路修顺了。

① 解析器终于认得出手机复制的格式

这是最要命的一个 bug：手机微信「长按 → 多选 → 复制」出来的格式是 张三：在干嘛，没有时间戳。旧解析器只认带时间的两种格式， 所以说话人列表是空的 —— 表现就是「导入了但分析不出来」。

现在三种格式都能正确分离说话人：

① 手机复制（最常用）        ② 电脑导出三段式          ③ 名字+时间
张三：今天加班吗            2024年1月1日 12:00         张三 2024-01-01 12:00
我：加啊                    张三                        在干嘛
张三：那你几点回            在干嘛                      我 2024-01-01 12:01
                            我                          没干嘛
                            没干嘛

② 界面改成复制优先

  • 主按钮从「粘贴剪贴板」改成 「粘贴我复制好的聊天记录」，做成整行的主按钮
  • 自动检测剪贴板：一进设置页（或从微信切回来）就看一眼，如果发现里面有 3 行以上文字，直接弹出一条提示「剪贴板里有 N 行文字，是从微信复制的聊天记录吗？→ 点这里一键导入」
  • 「从微信选文件」降级到折叠说明里的一行小字链接，不再当主入口
  • 最短长度限制从 20 字放宽到 8 字（复制两三条短消息也能过）

三、登录：微信头像 + 昵称 + 手机号

「我」页点登录后，走的是和其他小程序一样的流程：

┌─────────────────────────┐
│        微信一键登录       │
│                          │
│         ⬤  ← 正圆       │
│      选微信头像           │
│                          │
│  ┌────────────────────┐  │
│  │ 点这里填入微信昵称   │  │
│  └────────────────────┘  │
│  ┌──────────┐ ┌────────┐ │
│  │ 手机号    │ │一键填写│ │
│  └──────────┘ └────────┘ │
│                          │
│  ┌────────────────────┐  │
│  │        登录         │  │
│  └────────────────────┘  │
└─────────────────────────┘
  • 头像框锁死正圆：外层固定正方形容器 + 内层图片绝对定位铺满（以前 button 会被撑成椭圆）
  • 按钮文案：没登录显示「登录」，已登录显示「保存」
  • 手机号：先试微信一键填写，拿不到就手填（可留空）
关于「一键填写手机号」：微信要求企业主体小程序才能用，个人主体点了会失败。 失败时不会卡住，会提示手填。等哪天你换成企业主体，这个功能自动就亮了。
