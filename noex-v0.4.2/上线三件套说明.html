1用户服务协议

入口：我 → 用户服务协议（在「关于断联日记」卡片里，隐私指引上面一条）

八节，全是大白话：这是什么 / 你的数据存在哪里 / 关于小白和影子 / 你需要遵守的 / 免责 / 遇到危机时 / 内容与版权 / 协议变更与联系。

里面特意写清了三件容易被挑的事：

  • 不提供医疗服务，也不是咨询服务——避免被当成医疗行为
  • 对话内容会经云服务转发给第三方大模型（DeepSeek）用于生成回复，并提醒别发身份证号、银行卡号这类信息
  • 影子的回复不代表那个人，别把它当成对方的回应

页面底部还有一个入口，可以直接打开微信托管的《用户隐私保护指引》。

2意见反馈

入口：我 → 意见反馈。弹层里两条路：

  • 在线留言——直接打开微信客服会话，你在这里能看到并回复用户
  • 复制反馈模板——不依赖后台的备用路径。自动带上版本号、AI 模式、设备、使用天数、时间，用户贴上就能发
看到那句「登录后才能使用这个功能」了吗——客服是需要你在后台开通一次的，见下面第 4 张卡片。 没开通时点「在线留言」会提示未开启客服功能，所以我把「复制反馈模板」做成了兜底。

3分享（好友 + 朋友圈）

入口：右上角菜单 → 转发；首页还多了「分享到朋友圈」。小白、影子、留白瓶页也都能转发给好友。

文案是刻意做素的：

  • 标题只从「把时间留给自己 / 今天也要好好过 / 慢一点，也没关系」里随机取，不出现断联、前任、失恋、天数
  • 配图用不带字的白狐狸，不是小程序截图——截图会把标题栏「断联日记」一起带出去
  • 落地页是引导页：老用户会被自动送进首页，新用户看到完整介绍
这是断联日记，卡片上写着「我在用断联日记」等于替用户向所有好友公开私事，没人敢转。 所以分享出去的东西和情绪、感情完全不挂钩——别人看不出这是什么产品。

4你要做的一步：开通客服

mp 后台 → 功能 → 客服 → 添加客服人员（填你自己的微信号，用微信扫一下绑定）。

  • 登录 mp.weixin.qq.com，左侧「功能」里找「客服」
  • 点「添加客服人员」，填你常用的微信号，让对方扫二维码确认
  • 回到小程序，点「我 → 意见反馈 → 在线留言」，能打开会话就成功了
没配也能上线，只是用户点「在线留言」时会看到「该小程序未开启客服功能」。 建议配一下——用户遇到问题无处可说，最后都会变成应用商店里的一星评价。

5顺手修的两个真问题

  • 留白瓶写完一条，输入框不清空——和小白、影子是同一个坑（原生 textarea 在聚焦时忽略 value 更新），上次修那两页时漏了留白瓶，今天补上了
  • 「所有数据仅保存在本机，不上传服务器」表述不实——接了 AI 之后，对话内容确实会发给大模型，这句话站不住。已改成：「断联记录、留白瓶只存在你的手机里；只有你在对话里主动发送的内容，会用于生成回复」。隐私弹窗里同款表述也一起改了

运营者：本小程序的开发者（已登记个体工商户）。
