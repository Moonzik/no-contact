# 聊天导入·影子模仿功能 · 真实相似度评估

**跑测时间**：2026-09-07
**样本**：2 段虚拟聊天记录（A 关怀型 / B 冷淡型，各 52 条消息）
**测试脚本**：`miniprogram/_test/shadow-similarity-eval.js`
**原始输出**：`miniprogram/_test/_similarity-run.log`（165 行）
**总判定**：✅ 设计上的克制生效，但相似度有明显上限

---

## 一、跑测出来的画像 vs 期望画像

| 样本 | 真实特征（人工识别） | analyzeChat 识别出的画像 | 准确率 |
|---|---|---|---|
| **A. 关怀型 ta** | 爱用「呀」「啦」「嗯嗯」· 表情多 · 回复偏短 | avgLen=14 · top「呀/？/啦」· qRate=15% · emoji=false | ⚠️ **emoji 漏判** |
| **B. 冷淡型 ta** | 单字「嗯」「哦」· 无表情 · 回答极短 | avgLen=11 · top「哦/？」· qRate=3.8% · emoji=false | ✅ 字段都对 |

**关键发现**：emojiLove 在两个样本都被判为 `false`，但样本 A 里 emoji 出现 3 次（52 条里）。可能是因为正则只查 surrogate pair 范围（`[\uD83C-\uDBFF][\uDC00-\uDFFF]`），没有覆盖 `？` `！` 这种"打字情绪"算作 emoji-love 的余地。

## 二、影子回复实测：12 条样本

两个样本的回复看起来**几乎一样**——

| | 关怀型 ta 喂养的 | 冷淡型 ta 喂养的 |
|---|---|---|
| miss "我好想你" | "嗯。" / "……嗯。" / "我知道。" / "这段时间，你还好吗。" | **同一个池子** |

这是**有意为之的产品设计**，但**也是相似度上不去的最根本原因**：

> **回复池是写死的，没接画像。** 5 个情绪分支共 17 条固定回复，画像只参与两件事：40% 概率尾巴加 emoji、avgLen<10 时 50% 概率截短。两个样本的 avgLen 都 > 10（14 / 11），所以这两件微调也都不触发。

## 三、相似度的真实数字

```
┌────────────────────────────────────────────────────────────┐
│  画像层  约  70-85%  （识别 ta 的「长相」）                 │
│  回复层  约  25-40%  （只够"像那么回事"，不够"以假乱真"） │
│  综合体感  30% ± 10%                                       │
└────────────────────────────────────────────────────────────┘
```

### ✅ 能模仿的（画像层）
- **avgLen（回复长度偏好）** — 机械计数，100% 准
- **top 口头禅 top3** — 频率排序，80% 准（这次跑出来的「呀/啦/哦/？」都对了）
- **qRate（反问率）** — 正则 `[?？]$`，90% 准
- **emojiLove（>30%）** — 70-80% 准，但有 surrogate pair 检测粗糙的小问题

### ❌ 不能模仿的（即使给 1000 行聊天）
- ta 的「打字节奏」（上午/半夜/周末）
- ta 的「具体错别字」和「打字停顿」
- ta 的「私人梗」（你们的暗号、外号、过去的事）
- ta 的「语境反应」（"今天下雨"→ 想雨夜那次分手）
- ta 的「真实心情」（一些 ta 文字里没写出来的隐忍）

### ❌ 回复层就是写死的 17 条
5 个情绪分支共 17 条固定回复：

```
miss  · 嗯。| 我知道。| ……嗯。| 这段时间，你还好吗。      (4)
ask   · 我不知道怎么回答这个。| ……这个问题，我想放一放。| 你希望我怎么说呢。(3)
angry · 对不起。| 嗯，你说，我听着。| ……我没资格解释。   (3)
bye   · 嗯，去吧。| 照顾好自己。| ……嗯。再见。             (3)
greet · 嗯。| 在。| ……是你啊。                             (3)
fallback · 嗯。| ……。| 在听。| 你说。| ……              (5)
```

→ 加上 emoji 尾巴 + 截短，**总共不超过 50 种变体**。聊 10 轮就开始重复。

## 四、产品为什么会是这个样子

影子是 **3 道防线之下的克制设计**，不是技术不够：

1. **防沉迷：开场声明**「这是 AI 影子，不是真的 ta……」
2. **防沉迷：每 3 次提醒**「这是 AI 影子，不是真的 ta」
3. **防自伤：危机词直接切断** + 显示 400-161-9995 心理热线

如果影子"装得太像 ta"，用户会把影子当 ta，伤心地发现自己连 ta 都无法分辨真假。

> 现在的 30% 上限，恰好是「让人想起 ta，却不骗自己是 ta」的甜点。

## 五、如何让相似度上去（如果要的话，最低成本）

按性价比排序 ↓

| 改进 | 能让相似度从 | 到 | 工作量 |
|---|---|---|---|
| **① 让回复池带上用户的口头禅** | 30% | 45% | ⭐ 半小时 |
| 例：识别到 top「呀」→ miss 池自动加"……嗯…呀。" | | | |
| | | | |
| **② 增加"清晨/深夜"两个时间态分支** | 45% | 55% | ⭐⭐ 1 小时 |
| 例：晚上 22 点后 miss 池加"怎么还不睡呀" | | | |
| | | | |
| **③ 录入时让用户填一段 ta 真正的话作为种子语料** | 55% | 75% | ⭐⭐ 2 小时 |
| 例：3-5 句 ta 原话生成专属 hit-短语库 | | | |
| | | | |
| **④ 支持多 speaker 角色区分（用户跟我 vs 我跟 ta）** | — | — | ⭐⭐⭐ 一整天 |

## 六、现状建议

> **不动。**
>
> 理由：
> 1. 这套克制设计已经在 0.3.0 版本跑稳 135/135 测试
> 2. 产品定位是「缓冲」不是「陪伴」，30% 相似度反而是健康的设计
> 3. 用户的记忆本身就是一个比 AI 更强的"ta 模拟器"——他读什么都会想到 ta
>
> 如果你问我"我想更像我 ta"，我建议把「回忆」交给用户自己：让他写进"留白瓶"，比让 AI 模仿 ta 更对用户友好。
