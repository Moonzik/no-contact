# AI 接入 · 手把手版

> 这份文档假设你**从来没配过云开发、没听过 API Key**。
> 每一步都写清楚：点什么按钮、屏幕上会出现什么、你要填什么。
> 全程大约 20 分钟，中途随时可以停，停了不影响小程序正常使用。

---

## 第 0 步：先决定要不要做这件事

### 不做会怎样？

**什么都不做，小程序 100% 能用。** 小白和影子照常陪你聊、照常打卡、照常断联计时。

不接 AI 时，回复来自我写在程序里的规则引擎——能接住大部分情绪，但它是"命中关键词 → 抽一句预先写好的话"，
聊久了会觉得它在转圈圈、答非所问。

### 做了会怎样？

接上之后，回复由大模型生成，会**真的读你这句话**，能接住上下文，影子的模仿也更像真人。

### 代价是什么？

| 项目 | 说明 |
|---|---|
| 钱 | 要买大模型 API，约 **10 元起充**，一个用户正常聊大概能用几个月 |
| 时间 | 约 20 分钟，一次配好，之后不用管 |
| 风险 | 无。配错了最多是"接不上"，小程序会自动退回本地引擎，不会崩 |

### 【重要】中途放弃也没关系

任何时候卡住，只要 `utils/ai-config.js` 里还是 `provider: 'off'`，小程序就跟没接过 AI 一模一样。
**你不会把现有功能搞坏。**

---

## 第 1 步：搞懂三个词（30 秒）

后面会反复出现这三个词，先翻译成人话：

| 词 | 人话 |
|---|---|
| **API Key** | 大模型厂商给你的一串密码（形如 `sk-abc123...`），证明"用 AI 的人是你"，用多少扣你多少钱 |
| **云开发** | 微信官方送你的一个"小后台"，用来跑一段中转代码。不用买服务器、不用备案 |
| **云函数** | 上面那个小后台里跑的一小段代码。它的作用只有一个：**帮你把消息转发给 AI，再把 AI 的回复带回来**<br>因为密码存在它这里，别人拆开你的小程序也拿不到 |

一句话总结流程：

> 买密码 → 开通小后台 → 把中转代码传上去 → 把密码存进小后台 → 告诉小程序"去用那个后台"

## 第 2 步：拿到 API Key（约 5 分钟）

推荐用 **DeepSeek**，便宜、中文好、注册简单。

1. 浏览器打开 **https://platform.deepseek.com**
2. 用手机号注册并登录
3. 左侧菜单点「**API keys**」（有的版本叫「API 密钥」）
4. 点「**创建 API key**」，名字随便填（比如 `noex`）
5. **立刻复制那串 `sk-` 开头的东西，粘贴到记事本里。**
   ⚠️ 它**只会完整显示这一次**，关掉窗口就再也看不到了（只能删掉重建）
6. 左侧点「**充值**」，充 **10 元**够了

> **想先白嫖试试？**
> 智谱的 `glm-4-flash` 模型免费。注册 https://open.bigmodel.cn ，拿到 Key 后，
> 在第 5 步之后额外做一件事：给云函数加一条环境变量 `NOEX_AI_MODEL`，值填 `glm-4-flash`，
> 同时把云函数代码里 `host` 改成 `open.bigmodel.cn`、`path` 改成 `/api/paas/v4/chat/completions`。
> （这步稍微麻烦，新手建议还是用 DeepSeek 充 10 元。）

**【确认点】** 记事本里有一串 `sk-` 开头、长度大约 50 位的字符。

## 第 3 步：开通云开发（约 5 分钟）

### 先确认一件事：你是不是早就把云开好了？

很多人（包括你）打开控制台后找不到「开通」按钮，以为自己走错了——
**其实是因为已经开通了。** 「开通」这个按钮只在没开通时出现，开过一次就再也不会出现。

判断方法，看你现在屏幕上属于哪一种：

| 你看到的 | 说明 | 该做什么 |
|---|---|---|
| **左边有一排菜单**（概览 / 云函数 / 云后台 / 云数据库 / 云存储），顶部有个环境名 | **已经开通了** | 跳过本节，直接去下面「抄下环境 ID」 |
| 大字宣传页，讲云开发多强大、有个橙色按钮 | 这是**产品广告页**，不是控制台 | 点页面右上角「**控制台**」或「立即使用」 |
| 控制台是空的，中间只有一个虚线方框 | 还没建环境 | 点「**新建环境**」，等 1~3 分钟 |

> 常见误判：看到「云函数」「云后台」这两个菜单就以为还没开通——
> 恰恰相反，**能看到功能菜单，就说明环境已经建好了**。

### 方法 A：用浏览器开（推荐，最稳）

1. 浏览器打开 **https://tcb.cloud.tencent.com**
2. 点「**立即登录 / 免费开通**」，用**微信扫码**
3. 扫码后会让你选小程序 → 选「**断联日记NOEX**」（AppID `wx583936dd0c951ff5`）
4. 点「**开通**」，按提示走（可能要同意协议）
5. 新建环境：
   - 环境名称：随便填，比如 `noex`
   - 计费方式：选「**按量计费**」（有免费额度，不花冤枉钱）
   - 点确定，等 1~3 分钟
6. 环境建好后，页面上会显示一串**环境 ID**，形如 `noex-3gk8x9z2a1b4c6d`

**把环境 ID 也复制进刚才那个记事本。**

#### 环境 ID 抄不到？试这三个位置

1. 控制台左侧点「**概览**」→ 中间的**环境信息卡片**里，有一行「环境 ID」，右边有个复制图标
2. 点**页面顶部那个环境名旁边的下拉箭头** `▾` → 展开的列表里会写着环境 ID
3. 微信开发者工具 → 点「云开发」云朵 → 面板里的「**设置**」（齿轮图标）→ 环境 ID

环境 ID 长这样：`noex-3gk8x9z2a1b4c6d` —— **小写英文 + 数字 + 连字符**，
跟环境名（你自己起的 `noex`）是两个东西，别抄错了。

### 方法 B：在微信开发者工具里开

1. 打开微信开发者工具，载入「断联日记NOEX」项目
2. 看**窗口最顶上那条工具栏**，右上角位置，找一个**云朵形状的图标**，
   鼠标停在上面会显示"云开发"三个字
3. 点它 → 按提示开通 → 新建环境

### 方法 A、B 都找不到入口？

| 现象 | 原因 / 怎么办 |
|---|---|
| 工具栏没有云朵 | 把窗口**拉宽一点**，或者点工具栏最右边的 `···` 展开，云朵可能藏在里面 |
| 云朵点了没反应 | 开发者工具需要用**微信登录**，且这个微信号得是小程序成员 |
| 一直提示"请先开通" | 用法 A（浏览器控制台）绕过去 |
| 在 mp 微信公众平台后台找 | **那边没有云开发入口**，别找了，云开发不归它管 |

**【确认点】** 记事本里现在有两样东西：`sk-` 开头的密码 + 环境 ID。

## 第 4 步：把中转代码传上去（部署云函数）

回到**微信开发者工具**。

1. 看**左边文件树**（就是列着 pages、utils 的那一栏）
2. 找到一个叫 **`cloudfunctions`** 的文件夹，点开，里面有个 **`noex-ai`**
   - 正常情况它旁边会有一个**小云朵标志**，表示微信认出这是云函数
   - **如果没有小云朵**：关掉项目重新打开；还不行就检查 `project.config.json` 里
     有没有 `"cloudfunctionRoot": "cloudfunctions/"` 这一行
3. 在 **`noex-ai` 上点右键**
4. 选「**创建并部署：云端安装依赖**」
   （如果这项是灰的点不了 → 说明第 3 步没成功，回到第 3 步）
5. 右下角会弹出部署进度，等它提示「**部署成功**」

**【确认点】** 控制台区域出现绿色的部署成功提示。

### 这一步最常见的报错：`请在编辑器云函数根目录（cloudfunctionRoot）选择一个云环境`

意思是：**你还没告诉开发者工具要部署到哪个环境**。第一次部署一定会遇到。

解法（注意右键的是**根目录**，不是云函数目录）：

1. 目录树里右键 **`cloudfunctions`**（父目录）
2. 菜单里选「**选择云环境**」
3. 选中你的环境（`cloud1`）
4. 选完后，`cloudfunctions` 旁边会**冒出一个云朵图标** —— 看到云朵就说明绑好了
5. **然后**再右键里面的 **`noex-ai`** → 「上传部署」

> 两个目录别搞混：
> **根目录 `cloudfunctions`** → 右键是"选择云环境"
> **函数目录 `noex-ai`** → 右键才是"上传部署"

## 第 5 步：把密码存进去（环境变量）

这一步的目的是：让云函数知道你的 API Key，但又不会写进小程序代码里。

1. 打开云开发控制台（两种方式任选）
   - 浏览器：**https://tcb.cloud.tencent.com** → 扫码 → 进入刚才那个环境
   - 或者：开发者工具里点「云开发」云朵按钮
2. 左侧菜单点「**云函数**」
3. 列表里点 **`noex-ai`**
4. 点「**配置**」标签页（有的版本叫「函数配置」）
5. 往下找到「**环境变量**」区域，点「**编辑 / 新增**」
6. 加一条：

   | 变量名（左边） | 变量值（右边） |
   |---|---|
   | `NOEX_AI_KEY` | 记事本里那串 `sk-` 开头的密码 |

   ⚠️ 变量名必须**一模一样**，全大写，中间是下划线。值里**不要有空格**。

7. 点「**确定 / 保存**」

> **如果这步的界面你死活找不到**（腾讯云控制台改版很频繁），有个笨办法：
> 直接用开发者工具打开 `cloudfunctions/noex-ai/index.js`，
> 把第 26 行 `apiKey: ''` 的引号中间填上你的 Key，变成 `apiKey: 'sk-你的密码'`，
> 保存后**重新做一次第 4 步**（右键部署）。
> 缺点：Key 写在代码里，如果你以后把代码发给别人会泄露。自己用的话问题不大。

**【确认点】** 环境变量列表里能看到 `NOEX_AI_KEY` 这一条。

---

## 第 6 步：告诉小程序"去用那个后台"

1. 在开发者工具里打开 **`utils/ai-config.js`**
2. 找到第 **11 行** 左右：

   ```js
   provider: 'off',
   ```

   把 `'off'` 改成 `'cloud'`：

   ```js
   provider: 'cloud',
   ```

3. 再往下几行，找到：

   ```js
   cloud: {
     env: '',
     fn: 'noex-ai'
   }
   ```

   在 `env:` 的引号中间填**环境 ID**：

   ```js
   cloud: {
     env: 'noex-3gk8x9z2a1b4c6d',   ← 换成你自己的
     fn: 'noex-ai'
   }
   ```

4. **Ctrl + S 保存**，然后点工具栏的「**编译**」

改完之后这个文件关键部分应该是这样（只有这两处动了）：

```js
provider: 'cloud',          // ① 改了

cloud: {
  env: 'noex-3gk8x9z2a1b4c6d',  // ② 填了
  fn: 'noex-ai'
},
```

**【确认点】** 保存后编辑器里没有红色波浪线报错。

## 第 7 步：确认真的接上了

在开发者工具的模拟器里按顺序检查：

1. 底部 tab 点「**我**」
2. 往下滑到「**关于断联日记**」卡片，里面第二行小字就是 AI 状态（v0.9.2 起，关于内容全部平铺在页面上，不用再点头像旁边的齿轮）：

| 看到这行字 | 说明 |
|---|---|
| `AI 智能体 · 云函数` | 接好了，去聊天试试 |
| `AI 智能体 · 未接入（本地引擎）` | 没生效。检查第 6 步的 `provider` 是不是真的改成了 `'cloud'`、有没有点编译 |
| `AI 智能体 · 直连` | 说明 `provider` 填成了 `'https'`，改回 `'cloud'` |

3. 同一张卡片里还有完整版本号；再往下是「用户隐私保护指引」和危机热线
4. 进「小白」发一句话，比如「今天又忍不住看他的朋友圈了」
   - 接上了：回复会明显**针对这句话**，而且等 1~3 秒才出来
   - 没接上：回复几乎是**瞬间**出现的（本地引擎不用联网）

**【确认点】** 「我」页「关于断联日记」卡片里显示「AI 智能体 · 云函数」，且小白的回复有 1~3 秒延迟。

## 卡住了？对照这张表找

| 现象 | 最可能的原因 | 怎么修 |
|---|---|---|
| 关于卡片一直显示"未接入" | `ai-config.js` 没保存，或没点编译 | 保存 → 点编译 → 再看 |
| 显示"云函数"但回复是秒回 | 云函数调用失败，自动退回本地了 | 见下一条 |
| 回复慢但最终是本地那套话术 | Key 没配 / Key 错了 / 余额为 0 | 看第 8 步的日志排查 |
| 控制台报 `NOEX_AI_KEY 未配置` | 第 5 步环境变量没存上 | 重新做第 5 步，注意变量名全大写 |
| 报 `HTTP 401` | Key 填错或过期了 | 回 DeepSeek 重建一个 Key，重做第 5 步 |
| 报 `HTTP 402` 或 `insufficient balance` | 余额用完了 | 去 DeepSeek 充值 |
| 报 `环境 ID 不存在` | 第 6 步 `env` 填错 | 去云开发控制台复制正确的环境 ID |
| 完全没反应，也不报错 | 云函数没部署成功 | 重新做第 4 步 |

### 想看详细报错？开日志

1. 打开 `utils/ai-config.js`
2. 最后一行 `debug: false` 改成 `debug: true`
3. 保存、编译
4. 开发者工具底部点「**调试器**」→「**Console**」
5. 和小白聊一句，Console 里会出现 `[ai]` 开头的日志，里面有失败原因

排查完记得把 `debug` 改回 `false`。

## 关于钱

- DeepSeek 每条回复大约花 **0.002~0.005 元**
- 一天聊 20 条，一个月大概 **1~3 元**
- 微信云开发本身有免费额度，正常个人使用不会超
- 想设上限：云开发控制台 → 云函数 → `noex-ai` → 可以设调用频率限制；
  DeepSeek 后台也能设每月消费上限

## 不想用了？一键关掉

打开 `utils/ai-config.js`，把 `provider: 'cloud'` 改回 `provider: 'off'`，
保存、编译。立刻回到本地引擎，不再联网、不再花钱。

（云函数和 Key 留着就行，哪天想开再改回来。）

## 提审上线前必看

1. **隐私指引要改**：接了 AI 之后，用户导入的聊天记录片段会发给大模型商。
   `PRIVACY.md` 里已经写好了（「二之一、关于 AI 智能体」这一节），
   提审前要**同步到 mp 后台的隐私保护指引**，否则审核会打回。
2. **类目别乱改**：个人主体做 AI 对话有被拒风险，类目继续用「工具 → 效率」。
3. **"AI 影子 · 非真人"的标识别删**：这是审核要求的 AI 内容标识。
4. 如果提审时不想暴露 AI 能力，可以先把 `provider` 改成 `off` 再提审，过了再打开。
