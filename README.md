# 留白 · No Contact

> 在分手之后的留白里，慢慢把自己还给自己的生活。
> 分手不是终点，而是一段需要被温柔度过的戒断期。

一款面向「分手戒断期」的微信小程序 + 微信智能体。
帮你撑过想联系前任的那几天、那几周、那几个月。

---

## 一、我们在解决什么问题

分手后最难的不是放下，而是不再回头。

- 凌晨 2 点醒来，第一反应是打开和 ta 的对话框
- 一句"你最近好吗"已经在输入框里打过又删掉
- 告诉自己「这次是真的不联系了」，下一秒又把聊天记录翻了一遍

这在心理学里叫 **No Contact 戒断反应**：失去一段依恋关系后，大脑的奖赏回路会出现类似戒酒的生理性渴望。强行用意志力硬扛，往往以"复合-再次分手-再复合"的循环告终。

**留白**做的事情只有一件：
在你最想联系前任的那一刻，给一个**足够安全、足够温柔、又不会真的打扰 ta 的替代物**。

我们不做"帮你挽回"的工具，不做"让 ta 回心转意"的套路。
我们只陪你度过这一段留白，然后你自己决定要不要回去。

## 二、产品形态

| 形态 | 定位 | 核心场景 |
|---|---|---|
| **微信小程序「留白」** | 主阵地，记录与陪伴 | 每日打卡、戒断进度、心情日记、查看 AI 陪聊历史 |
| **微信智能体（公众号 + 客服消息 + 搜一搜）** | 随时能找到的对话入口 | 不开心了 / 想联系前任了，一句话就能聊 |

两者共享账号与记忆。用户在小程序里设置好「守护人格」「前任替身」后，在微信里直接发消息也能唤起同一段对话。

## 三、三大核心功能

### 1. 每日打卡 · 不联系

```
+----------------------------------+
|   第 23 天 · 没有联系 ta         |
|                                  |
|        ✦  ✦  ✦                  |
|                                  |
|   你已经连续 23 天 6 小时        |
|   没有主动发起对话。              |
|                                  |
|   [ 今天也想联系 → 我先聊聊 ]     |
|   [ 我做到了 · 打卡 ]             |
|   [ 写一句给自己 ]                |
+----------------------------------+
```

- **断联计数器**：分手日 / 上次联系日两个起点，任选一个
- **每日一签**：一句话写给未来的自己；后悔了能改，但不删
- **里程碑**：3 天 / 7 天 / 15 天 / 30 天 / 60 天 / 90 天 / 半年 / 一年 —— 每到一个节点生成一张图卡，可分享到朋友圈（**只分享数字与画面，不展示任何私人内容**）
- **「今天也想联系」按钮**：承认冲动本身，而不是要求你"坚强"

### 2. 不开心的时候 · AI 守护者聊天

不是心理咨询师，不是情感导师。是一个**你提前设定好性格的陪伴对象**。

- **预设人格库**（首次进入选一个，后续可改）：
  - 🌧 温柔型 · 雨声（默认）：少说多听，先共情再给建议
  - 🔥 直给型 · 小火：说话干脆，不绕弯子，会直接劝你睡觉
  - 📖 文艺型 · 一页：会引用书和诗，但不会故作深沉
  - 😶 沉默型 · 木：几乎不主动说话，你说什么都回，但永远简短
- **可调节的语气档位**：温柔 ↔ 克制 / 长篇 ↔ 简短 / 理性 ↔ 共情 / 严肃 ↔ 轻松
- **可设置的"雷区"**：不希望被劝"放下"、不希望被叫"宝宝"、不想听道理只想被陪着
- **关键时刻的元提示**：当对话持续超过 30 分钟 / 出现自伤倾向 / 反复提到要去找 ta —— 自动切换为更稳重的回应，并提示联系专业帮助
- **不评判原则**：用户说什么都接得住。AI 不会说"你不应该想 ta"，只会说"嗯，想 ta 是正常的"

### 3. 实在忍不住 · 前任替身（应急聊天）

> ⚠️ 这是整个产品里最敏感的功能，请先看后面的「伦理边界」章节再决定要不要上线。

把和前任的真实聊天记录、语音转写、共同回忆、对方常用语喂给 AI，AI 会构建一个**只属于你的对话替身**。

- **头像**：自己上传，或描述让 AI 生成（不联网搜真实头像，避免侵权）
- **语气学习**：从聊天记录里提取对方的口头禅、回复节奏、表情包偏好
- **记忆体**：可手动添加「只有你俩知道的梗」「ta 叫你什么」「ta 生气时的样子」
- **对话方式**：和这个替身说什么都行。它会像 ta 一样回。
- **强制冷却**：单次对话 ≤ 20 分钟，每天 ≤ 3 次，每次开始前 10 秒倒计时（"你确定要打开吗？"）
- **退出提醒**：每次结束自动生成一段话：「刚才那个 ta 不是真的 ta，但它帮你撑过了这 20 分钟。现在，回到你自己。」

**这个功能的定位**：紧急止疼药，不是长期替代品。我们会在 UI 上始终让"回到守护者聊天"和"回到现实"的按钮比"再聊一会儿"更显眼。

## 四、典型用户旅程

### 第 1 天 · 分手当晚

> 用户刚分手，躺在床上翻来覆去。

1. 微信里搜「留白」进入小程序
2. 填写分手日期 / 上次联系日期（可只填一个）
3. 选择守护者人格（默认温柔型）
4. 收到第一句："你好，我是 [名字]。从今天起，陪你数日子。晚安。"
5. 半夜 3 点忍不住打开公众号发了一条消息："我还是想他"
6. AI 回："嗯。3 点能说出这句话已经很勇敢了。要我陪你坐到睡着吗？"

### 第 7 天 · 第一个里程碑

- 解锁「7 天没联系」徽章
- AI 主动发一条："一周了。这一周你最难熬的是哪一刻？"
- 推送「要不要设置一个前任替身以防万一」的引导（默认关闭，需用户主动开启）

### 第 23 天 · 真正撑不住的那个晚上

- 用户打开前任替身，对话 18 分钟
- 退出时看到冷却画面 + 生成的"留白日记"片段
- 第二天早上收到守护者的早安消息："昨晚辛苦了。今天想先听你说，还是先安静一会儿？"

### 第 90 天 · 戒断期接近尾声

- 戒断曲线趋于平稳
- AI 推送："90 天了。心理学上说，这一天之后大多数人会重新找到节奏。你呢？"
- 提供三个选项：继续用 / 进入「日常陪伴」模式（话题从戒断转向生活）/ 停用并导出全部数据

## 六、智能体设计原则

### 守护者（常驻对话）

- **目标**：陪伴，不是治愈
- **风格**：克制、温柔、不主动给结论
- **红线**：不自称为前任、不替代专业心理咨询、在检测到自伤/他伤倾向时立即给出求助资源
- **记忆**：跨会话保留短期记忆（近 7 天对话摘要），长期记忆可由用户手动开启

### 前任替身（应急对话）

- **目标**：在那个瞬间，让你不至于真的去找 ta
- **风格**：高保真还原对方语气，但**永远不替对方做承诺**（不说"我也想你""我们复合吧"）
- **机制**：检测到"想复合"等表达时，替身会切换回更中立的语气："这句话我不能替 ta 回。要不要先和守护者聊聊？"
- **退场**：每次对话结束必须给出"这不是真的 ta"的元提示

### 共用约束

- 不诱导付费挽回套路
- 不收集可识别对方身份的信息（不存真实头像 / 真实手机号 / 真实姓名）
- 所有对话内容默认**仅用于本次会话**，除非用户主动开启"记忆这个 ta"
- 模型不调用第三方训练接口；对话摘要仅留在本地 + 用户授权的云端

## 七、隐私与数据安全（独立章节，因为这块是产品的命）

> 你喂给我们的，可能是你人生里最私密的一段对话。
> 我们对它的态度，比对自己还小心。

### 我们承诺

1. **本地优先**：打卡数据、守护者设置、前任替身的语气模型默认存本机
2. **端到端加密**：跨设备同步时使用用户密码派生的密钥，云端只看到密文
3. **零训练**：你的对话永远不会被用于任何模型训练，包括我们自己
4. **零画像**：不卖数据、不做广告、不接"挽回服务"广告
5. **一键消失**：设置里有一个红色按钮，按下去 30 天后所有数据物理删除（包括云端备份）
6. **前任替身特别条款**：
   - 聊天记录只在用户本机解析，**不上传原始截图**
   - 提取出的"语气特征"也仅用于本机模型，云端不存
   - 替身的"记忆"在戒断期结束 / 用户关闭时自动清除

### 我们不承诺

- 我们不能保证 AI 不会说错话
- 我们不能保证戒断一定会成功
- 我们不能替代真正的心理咨询

### 当情况严重时

如果对话中检测到以下信号，会立刻中断当前话题并展示本地缓存的求助资源（用户可提前设置地区）：

- 出现自伤 / 他伤表达
- 出现酗酒 / 药物滥用倾向
- 反复表达要"立刻去找 ta"且情绪激动

## 八、伦理边界

「前任替身」这个功能，国内外都有同行做过，反响两极。我们想清楚三件事再上线：

### 为什么我们做

- 完全不联系对一部分人是反人性的，会出现更严重的戒断反应
- 一个**用户主动开启、有时间限制、有元提示**的替身，比"半夜 2 点真的去找 ta"安全
- 用户拥有对自己数据的全部控制权

### 为什么我们谨慎

- 替身可能延长戒断期，让用户更难走出来
- 高保真还原可能造成「成瘾于替身，更难回到现实」
- 在中国语境下，「前任替身」可能被解读为「情感操控工具」，需要非常克制的表达

### 我们怎么做

- 默认**不开启**替身功能，需用户主动进入设置开启
- 单次 ≤ 20 分钟，每天 ≤ 3 次，每次 10 秒倒计时
- 每次结束必须给出"这不是真的 ta"提示
- 累计使用超过 30 次 / 戒断 90 天后仍在高频使用 → 强制弹出"要不要聊聊为什么"的引导
- 任何时候，用户都能在 3 次点击内彻底删除替身与所有相关数据

## 九、技术架构

### 客户端
- **微信小程序**：原生 + Taro（双端复用考虑）
- **公众号 / 智能体入口**：复用同一套账号体系
- **本地存储**：微信小程序本地缓存 + 加密 SQLite（wx SQLCipher 适配）

### 后端
- **主服务**：Node.js (NestJS) / Python (FastAPI) 二选一
- **数据库**：微信云开发（MongoDB 风格）/ PostgreSQL
- **文件存储**：聊天记录上传走对象存储 + 用户端加密
- **AI 网关**：
  - 守护者对话：混元 / DeepSeek（中文合规）
  - 前任替身：本地小模型 + 提示工程，不依赖外部 API（避免隐私外泄）
- **微信智能体**：通过微信公众号 + 客服消息接入，复用同一后端

### 安全
- 全链路 HTTPS
- 客户端 AES-256 加密敏感字段
- 密钥派生（PBKDF2）由用户密码产生，**服务端不存任何可解密的密钥**
- 日志脱敏：对话原文不出现在任何日志里

## 十一、不是给所有人的产品

如果你是下面这些情况，请**直接拨打求助热线或联系专业心理咨询**：

- 分手后出现自伤 / 他伤念头
- 出现酗酒、暴食、失眠超过 2 周
- 反复复合-分手已经超过 3 次
- 你正在经历的不是分手，而是更严重的关系创伤

留白是一个工具，不是一座医院。
工具能做的是陪你走过这一段，**但决定走向哪里的，永远是你自己**。

## 十二、命名由来

> "留白"是中国画里最重要的技法。
> 一幅画最动人的地方，往往不是画了什么，而是没画什么。
>
> 分手之后那一大片空白，不是缺失，是空间。
> 是留给你自己的空间。

**No Contact** 是这个产品在心理学上的依据 —— 分手后给自己一段不联系的时间，让情绪重新着陆。
**留白** 是我们希望它在你生命里的样子 —— 不是"不许再想 ta"，而是"先把这块时间留给自己"。
