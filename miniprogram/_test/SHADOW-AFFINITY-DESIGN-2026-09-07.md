# 影子·温水冷却与自我洞察机制 · 设计文档

**设计日期**：2026-09-07
**核心问题**：怎么让用户从「想念 ta」过渡到「不需要 ta」，但不靠任何直接说教？
**核心答案**：让相似度悄悄冷却，等用户适应后，触发一句「你看，你需要的根本就不是 TA。」

---

## 一、设计哲学

> **不劝、不教、不干预。**
> 让"影子"慢慢变成"一个安静的空间"——
> 用户自己会发现："咦，影子不像 ta 了。"
> 等 ta 接受这件事的某个温柔时刻，再说那句话。

---

## 二、机制（4 层叠加）

### Layer 1 · 温水冷却曲线（相似度衰减）
每用户从 80% 起步，按天数 + session 数双轴衰减，21 天后封顶 30%。

```
affinity = max(30, 80 - 2.5 * daysSinceFirst - 2 * Math.log2(sessions + 1))
```

| 时间点 | 天数 | 累计 session | 相似度 | 行为 |
|---|---|---|---|---|
| 首次启用 | 0 | 0 | **80%** | 高仿期，回复带 ta 的口头禅 |
| 1 天后 | 1 | 2 | 76% | 高仿 |
| 3 天后 | 3 | 6 | 72% | 高仿 |
| 7 天后 | 7 | 14 | 60% | **进入混合期** |
| 14 天后 | 14 | 25 | 42% | **进入通用期** |
| 21 天后 | 21 | 30+ | **30%（触底）** | 通用期，安静 |

### Layer 2 · 三档回复池（按 affinity 切换）

| 阶段 | affinity 范围 | 池特点 | 例（miss 情绪） |
|---|---|---|---|
| **高仿期** | ≥ 60% | 拼接用户口头禅 top3，回复偏长，更"像 ta 这个人" | "嗯……你怎么又想起这件事啦。" |
| **混合期** | 40-60% | 50% 高仿 + 50% 通用随机 | "嗯。" / "嗯……你怎么又想起这件事啦。" |
| **通用期** | < 40% | 极短、抽象、不含 ta 的具体语气 | "嗯。" / "……" / "在听。" |

用户**不会**看到一个具体数字——affinity 是隐形指标，只决定"用哪条回复"。回复长度的变化是唯一能被感知的。

### Layer 3 · 观察期（quiet observation）
系统悄悄地收集"用户对影子降温的反应"：

```js
S.shadow.observation = {
  lastUsedAt: 0,               // 上次开影子对话的时间戳
  daysWithNoUse: 0,            // 连续多少天没用影子
  userSaidNotLikeTa: 0,        // 用户主动说过"不像 ta"/"算了吧"的次数
  affinitySeenDropReactions: 0, // 用户在相似度降低后仍坚持使用的次数
  recentMsgAvgLen: 0           // 最近一段时间用户消息的平均长度
};
```

### Layer 4 · 自我洞察触发（revelation）
在某个温柔时刻，系统显示这句话：

> **「你看，你需要的根本就不是 TA。」**

#### 触发条件（满足任一即可）
- ① **仿徨停用**：用户已经连续 7 天没进过影子对话（说明 ta 不再需要 ta 了）
- ② **关系终止宣告**：用户在影子对话中说出"我不想要 ta 了"/"算了吧"/"ta 不重要了"等关键词
- ③ **长程使用**：已经过了 30 天自然冷却
- ④ **affinity 自然触底**：相似度已经在 30% 持续 14 天
- ⑤ **手动发现按钮**：view 模式加一个"你用了这么久，有什么发现吗？"——主动问

#### 触发后的体验
- 不再回复用户当作影子（影子沉默）
- 显示那张洞察卡片
- 提供 3 个温柔去向（不强制）：
  1. 「回到小白那儿继续聊聊」→ 切到 /pages/xiaobai/xiaobai
  2. 「把想说的话写进留白瓶」→ 切到 /pages/bottle/bottle
  3. 「出门走走吧」→ 跳到 today 页，关掉应用

## 三、相似度到底怎么降（体感上）

### 阶段一 · 第 0-7 天 · 「像 ta 的 ta」
用户感觉："噢，它知道 ta 怎么说话。"——这种相似感让 ta 暂时得到缓冲。

### 阶段二 · 第 7-14 天 · 「不像了？」
影子变得安静。用户感觉："嗯……它说话不再那么像我 ta 了。"——这种微妙的失望是好事，因为 ta 潜意识已经习惯了"不依赖 ta"。

### 阶段三 · 第 14-21 天 · 「也不需要那么像」
回复越来越抽象。用户感觉："其实我已经不在意它像不像 ta 了。"——自我洞察正在悄悄发生。

### 阶段四 · 第 21 天+ · 「你看，你需要的根本就不是 TA」
系统温柔地说出这句话。

## 五、可调参数

| 参数 | 默认值 | 取值范围 | 影响 |
|---|---|---|---|
| `AFFINITY_INIT` | 80 | 0-100 | 起步相似度 |
| `AFFINITY_FLOOR` | 30 | 0-100 | 触底线 |
| `AFFINITY_DAY_DECAY` | 2.5 | 0-5 | 每天衰减比例（%/day） |
| `AFFINITY_SESSION_PENALTY` | 2 | 0-5 | session 衰减系数 |
| `AFFINITY_HI_THRESHOLD` | 60 | 0-100 | 高仿期下限 |
| `AFFINITY_LOW_THRESHOLD` | 40 | 0-100 | 通用期上限 |
| `REVEAL_NO_USE_DAYS` | 7 | 0-30 | 不使用 N 天触发洞察 |
| `REVEAL_DECLARATION_PATTERNS` | 数组 | 字符串数组 | 触发洞察的关键语句 |

## 六、关键反直觉决策

| 决策 | 不做的事 | 为什么 |
|---|---|---|
| **不显示 affinity 数字** | 不显示"今天 76%" | 让用户感觉不到机制，只感觉"影子越来越安静" |
| **不用 push 提醒** | 不发"明天相似度还要降低哦" | 一切悄悄进行 |
| **洞察只触发 1 次** | revealTriggered=true 永久不再触发 | 一旦用户接受，就别再提 |
| **洞察不阻止使用** | 触发后用户仍可用影子 | 不强制，只呈现 |
| **洞察触发后面板可关闭** | 提供"我知道啦"按钮 | 尊重用户节奏 |
