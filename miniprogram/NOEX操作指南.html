1装新版开发者工具 + 导入项目20 分钟

为什么必须装新版：你现在装的是 1.06.2303220（2023 年 3 月）， 而我们用的隐私授权 API 是 2023 年 9 月才出的。老工具不认识它， 所以才会报「目录无效 / 文件夹名无效」这种莫名其妙的错。
  1. 完全关掉现在打开的旧版开发者工具
  2. 双击桌面上的 wechat_devtools_2.02.2608070.exe 安装
    直接覆盖安装，不用卸载旧的，项目列表和登录状态会保留。
  3. 打开新工具 → 点中间大 「＋」 → 顶部切换到 「导入项目」
    ⚠️ 默认是「新建项目」，两个长得像，选错了也会报错。
  4. 目录填这个（直接复制）：
    C:\Users\XIAOMI\Desktop\noex
    要选的是刚好包含 app.json 和 project.config.json 的那一层，也就是 noex 本身。选到 pages、utils 这类子目录会报「不是小程序项目」。
  5. AppID 一般会自动带出 wx583936dd0c951ff5，没带就手填
  6. 后端服务选「不使用云服务」→ 点导入
成功标志：能看到模拟器显示小程序界面。报错就把截图发我。

2上传代码 v0.9.85 分钟

  1. 顶部菜单栏 「工具 → 上传」
    底部的上传按钮在某些版本会被折叠，从菜单栏进最稳。
  2. 版本号填 1.0.0（对外展示用，首次上线填这个合适）
  3. 项目备注复制下面这段（审核员会看）：
断联日记 NOEX —— 分手断联期的自我陪伴工具

【功能说明】
1. 今天：显示断联天数、每日一句鼓励语、打卡记录
2. 小白：白狐狸形象的陪伴者，4 种性格可选，像普通朋友一样聊天，不主动说教
3. 影子：粘贴微信聊天记录后，模仿对方语气，陪你把没说完的话说完
4. 留白瓶：写下想说但不会发出去的话存起来，永远不会被发送
5. 我：微信头像+昵称登录、关于、隐私保护指引、公益求助渠道

【本版更新】
- 完善《用户隐私保护指引》与隐私授权弹窗
- 优化对话贴合度：用户说什么就回什么，不再生硬往情感话题上靠
- 修复聊天消息布局，优化头像显示

【体验说明】
- 无需登录即可体验全部主要功能（今天 / 小白 / 影子 / 留白瓶浏览）
- 仅「往留白瓶写字」「个人资料」需要微信头像昵称授权
- 所有数据仅保存在用户手机本地，不上传服务器
- 不涉及任何付费、交易、社交匹配功能
最后那句「不涉及付费、交易、社交匹配」别删 —— 审核员最怕这类，主动声明能明显加快过审。 这是提审话术，不是永久承诺：上线之后想加什么都行。

3.1 提交审核

  • 测试账号：选「无需测试账号」（我们没强制登录）
  • 滚到页面最底部，找「用户隐私保护指引设置」→ 选「采集用户隐私」

官方权限名称用途描述（直接复制）

3.3 三个最容易漏的必填项

  • 联系方式邮箱：没有就现注册一个（QQ 邮箱就行）。这栏空着会直接驳回。
  • 存储期限填这句：
    仅存储于用户设备本地，卸载小程序即删除；开发者服务器不保存任何个人信息
  • 还有一空：「再次以 ____ 方式告知」 → 填 弹窗
    别填短信/电话/邮件 —— 你没有这些推送能力，等于承诺做不到的事。我们代码里确实有弹窗页，前后对得上。

3.4 SDK 信息那栏

项目零第三方 SDK（无插件、无 npm 依赖、无自定义组件）。 SDK 信息填「无」或「未使用第三方 SDK」；是否使用插件 → 否；基础库版本 → 2.32.3。
提交后等 1～2 个工作日。这段时间里真机上的头像/昵称/手机号是用不了的（平台拦截，代码绕不过），属正常现象。

4个人 → 个体工商户（完整流程）1～2 周

先说结论：不用重做小程序。
微信主体变更的官方条件只写了「目标主体不支持为个人类型」——禁止的是"变成个人"， 没禁止"从个人变出去"。所以 AppID、名称「断联日记 NOEX」、代码、用户数据全部保留。
要花的只有：办执照（免费）+ 公证书（300～500）+ 微信审核费 300。
整条链路一共四小步：办执照 → 办公证 → 微信发起变更 → 重新备案。
其中公证最慢（3～7 天），备案最容易漏（漏了会被下架）。下面逐个说。

4.1 办理个体工商户营业执照1～3 天 · 政府已免费

好消息：个体工商户设立登记的行政收费已全面取消，官方不收钱。 线上全程电子化，多数地区 1 个工作日内办结，快的当场拿证、2 小时办结也有。

去哪办

渠道怎么走
线上（推荐）本省政务服务网 → 搜「个体工商户设立登记」/「企业登记全程电子化」。各省也有自己的 APP（随申办、粤商通、皖事通等）
线下经营场所所在地的市场监管所或行政服务中心 → 取号办「注册登记类」，很多地方当场出证

要准备的材料

  • 经营者身份证原件（线上要正反面照片 + 刷脸实名）
  • 经营场所使用证明，三选一：
    • 自有房产 → 房产证复印件
    • 租赁 → 租赁合同 + 房东房产证复印件
    • 住宅 / 没商用地址 → 居委会或物业开的场所使用证明（多数地区认可，先问一句）
  • 《个体工商户设立登记申请书》—— 线上会自动生成，线下窗口填
  • 名称（可自主申报，也能不设字号直接叫「XX市XX区某某经营部」）
纯线上、没有实体经营场所的情况：2025 年 7 月起施行的新规允许把「网络经营场所」登记为经营场所， 但需要电商平台出具的场所使用证明（淘宝、京东、拼多多这类会给；微信小程序一般不提供这种证明）。 能不能用，办之前打当地市场监管所电话问一下最稳。

⚠️ 三个关键决策（写错会直接影响后面）

① 经营范围怎么写 —— 这是整件事里最要命的一栏

推荐勾选（在系统的规范库里勾，别自己造词）：
经营范围条目为什么需要
技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广核心项，对应「做软件/小程序」
软件开发同上，更直白
信息技术咨询服务覆盖工具型服务
互联网数据服务覆盖数据存储、记录类功能
广告设计、代理以后开流量主接广告用得上
日用百货销售 / 文具用品零售以后卖实体周边用得上

❌ 绝对不要写：心理咨询、健康咨询、教育咨询、情感咨询、婚恋服务

为什么：执照上一旦写了「心理咨询」，微信就一定会来要 3 位持证咨询师的资质证明； 不写，平台根本不会往这个方向查你。
经营范围的原则是够用就好，别贪多 —— 多写一项，就多一条被追问的路径。
② 名称里也别带敏感词
格式是「行政区划 + 字号 + 行业 +（个体工商户）」，比如 XX市XX区断联日记网络技术工作室（个体工商户）。
名称中不要出现「心理」「咨询」「情感」「医疗」这类字 —— 平台扫名称，和你实际做什么无关。
③ 经营者姓名必须是你本人
这是微信主体变更的硬条件：个体户执照上的经营者姓名， 必须和小程序原个人主体的身份证姓名完全一致。
如果执照写的是家人或朋友的名字 → 100% 驳回，300 元审核费也不退。

拿到执照之后（别漏）

  • 30 日内必须做税务登记，否则可能罚款。多数地区线上就能办，也可以在税务大厅
  • 电子营业执照：微信搜「电子营业执照」小程序可以直接领，与纸质执照同等法律效力
  • 刻章：非必需，但以后开对公账户会用到（部分地区免费刻）
顺带一个定心丸：按 2025 年 7 月新规，个体工商户以后可以转型为公司并保留原统一社会信用代码和成立日期。 所以现在办个体户不是"死路"—— 以后真要做大了转企业，主体能延续。

4.2 办公证书3～7 天 · 300～500 元

为什么个人变更必须要公证：正常情况下个体户变更可以法人扫脸验证。 但你的原主体是个人，没有"法人"可扫，所以必须用公证书来证明"这个小程序确实是你本人的"。
  1. 找当地公证处（或支付宝/微信搜「公证云」线上办，快一些）
  2. 公证事项：声明书公证 / 小程序主体变更声明
  3. 带这些材料：
    • 身份证原件
    • 个体工商户营业执照原件（刚办下来的）
    • 小程序信息页截图（mp 后台 → 设置 → 基本设置 → 主体信息）
  4. 跟公证员说明用途：用于微信小程序主体从个人变更为个体工商户
  5. 拿到公证书（纸质 + 电子版都要）
费用各地不同，一般 300～500 元。线上公证便宜些，但有些地区微信不认， 办之前先问一句"能不能用于腾讯小程序主体变更"。

4.3 微信后台发起主体变更1～3 天 · 300 元

先自查这三条（不满足会被驳回）

  • 个体户执照的经营者姓名 = 你本人（上面 ③ 说过了，最大的驳回原因）
  • 营业执照在有效期内、状态正常
  • 小程序无未完成的违规处罚、无进行中的交易

操作路径

mp.weixin.qq.com → 设置 → 基本设置 → 主体信息 → 小程序主体变更
  1. 目标主体类型选「个体工商户」
  2. 填统一社会信用代码、执照上的名称（照抄执照，一个字别差）
  3. 上传三样：营业执照照片 + 经营者身份证正反面 + 公证书
  4. 验证方式：会提示不能扫脸 → 走公证书通道（就是 4.2 办的）
  5. 按提示完成验证、签署变更协议
  6. 支付 300 元审核费
    ⚠️ 这笔钱审核失败也不退，所以先把材料核对清楚再交。
  7. 提交，等 1～3 个工作日
成功标志：主体信息页显示的是你的个体户名称，主体类型变成「个体工商户」。

4.4 立刻重新备案1～20 天 · 免费

这是最容易被忽略、后果最严重的一步。
主体变更 = 统一社会信用代码变了。官方不支持直接修改备案， 必须先注销原备案，再用新主体重新申请。

中间存在备案真空期，而未备案的小程序会被下架。
  1. 主体变更通过后，当天就去备案（别拖）
  2. mp.weixin.qq.com → 设置 → 小程序备案
  3. 先注销原来的个人备案
  4. 再用个体户主体重新提交备案申请
  5. 填服务内容时，类目选「工具 → 效率」（见下面红线章节）
  6. 等审核（各省管局速度不同，一般 1～20 天）
备案期间小程序可能被下架，属正常流程，备案通过后会自动恢复。 这段时间别慌，也别重复提交。

5变更后还要做三件事半天

5.1 重选服务类目（原类目已失效）

mp.weixin.qq.com → 设置 → 基本设置 → 服务类目 → 删除旧的 → 重新添加
选什么说明
✅ 工具 → 效率首选。我们实际做的就是记录、打卡、聊天工具。
生活服务 → 其他备选，如果「工具-效率」被驳回就换这个。
❌ 社交 → 社区/论坛、笔记需要《增值电信业务经营许可证》，你没有。
❌ 商业服务 → 心理咨询需要 3 位持证咨询师 + 合作协议，你没有。

5.2 更新隐私指引的主体信息

主体变了，隐私指引里的主体信息要同步更新，再提交过审一次（1～2 个工作日）。勾选项和之前一样，还是那 6 项。

5.3 重新提审

类目和隐私指引都过审后，重新提交一次代码审核。代码不用改，直接用现有的 1.0.0 版本提交。

!合规红线：写任何文案前先过一遍

个体户 ≠ 能做情感咨询。
微信心理咨询类目硬门槛：执照经营范围明确含「心理咨询/健康咨询」 + 3 位持证咨询师资格认证 + 3 人的合作协议或劳动合同。你没有，换什么主体都过不了。

真实翻车案例：有个「情绪陪伴」小程序功能完全没问题， 只因名称/描述里出现「心理咨询」四个字，被机器判定"可能涉及医疗行为"， 半年被罚两次后封号。机器扫关键词，不管你实际功能是什么。
❌ 禁用词✅ 替代表达
咨询、疏导、疗愈、治愈记录、陪伴、撑住、说说话
抑郁、焦虑症、心理治疗情绪低落、难受、撑不住
挽回、恋爱教学、挽回指导断联记录、情绪日记
最、第一、唯一、全网、天花板很、挺、特别（极限词也别用）
100%、永久、根治、保证通常、大多、慢慢来
这套红线对执照同样适用：经营范围、个体户名称、小程序名称、版本描述、小红书简介， 五个地方口径要完全一致 —— 都是「工具 + 记录 + 陪伴」，都不出现心理/咨询类词。 任何一处露馅，机器都可能串起来判定。
代码侧已经清理过一遍：每日一句的「疗愈不是直线」改成了「好起来不是直线」； 「我」页的公益求助热线保留（这是安全底线不能删）， 但加了一行小字「以下是国家公益求助渠道，不由本小程序提供」，用来撇清"本产品在提供心理服务"。

$上线后的变现节奏

第一阶段：攒人（上线 ~ 1 个月）

什么都别想，专心发内容拉人。小红书连载图（60 张已做好）现在就能开始发，每周 2 期。

第二阶段：开流量主（UV 达标后）

  • 门槛：累计独立访客 UV 达标（官方口径 1000，有说 2026 已降至 500，以你后台提示为准）
  • 路径：mp 后台 → 推广 → 流量主 → 签协议 → 绑银行卡
  • 收益参考：激励视频 eCPM 50～120 元 > 插屏 15～40 元 > Banner 最低
情感类产品用户处在情绪低谷，广告要克制。建议只开激励视频（用户主动点才出现）， 别上插屏弹窗 —— 伤留存，得不偿失。

第三阶段：付费（个体户才能做）

个体户主体可以开通微信支付了，这时候才能做会员/解锁。

iOS 端不能卖虚拟商品（苹果 IAP 规定）。所以会员类虚拟商品在 iPhone 上是受限的， 设计付费功能时要把这条算进去 —— 建议付费点设计成实体周边 / Android 专属， 或者干脆靠广告 + 小红书引流到私域变现。

?常见驳回原因对照

驳回话术怎么改
涉及 XX 接口，请完善隐私指引平台又扫出新权限了，补在提审页面（入口 2），别去设置页
