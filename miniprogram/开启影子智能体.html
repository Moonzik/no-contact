!先说清楚：影子为什么不说话

两个原因，都已修好。
  1. 云函数从来没部署过。代码里配的是走云开发云函数，但 noex-ai 一直没上传， 于是影子每次都回落到一套写死的短句（「嗯。」「……」）—— 就是你看到的"乱七八糟"。
  2. 代码里还有个真 bug。cloudInit() 在"已经初始化过"时反而返回失败， 导致第一次之后的每一次 AI 调用都被判定为云开发不可用。 小白因为有本地规则兜底所以你没察觉，影子就直接废了。
v0.9.9 已改：
  • 修掉 cloudInit 那个 bug（顺带小白也终于能真正用上 AI 了）
  • 影子取消本地兜底，改为纯智能体。AI 拿不到结果就说清楚原因，绝不再拿固定句库假装是 TA 在说话
  • 强化模仿：样本给到 10 条，并把「像 TA」写成第一优先级
所以现在只要把云函数部署上，影子和小白就都活了。

1部署云函数5 分钟

✅ 之前小白已经部署过 noex-ai 的话，这步直接跳过——小白和影子用的是同一个云函数， 影子不需要单独部署，也不需要重新上传（云函数代码没改过）。
⚠️ 不要在云开发控制台里新建同名的 noex-ai——同名函数只能存在一个，新建会报 "函数已存在"之类的错误。要用新代码更新已有函数，只需在开发者工具里右键它 → 上传并部署（覆盖式更新）。
  1. 开发者工具打开项目（目录 C:\Users\XIAOMI\Desktop\noex）
  2. 左侧文件树找到 cloudfunctions → noex-ai
  3. 右键 noex-ai → 「上传并部署：云端安装依赖」
    ⚠️ 选「云端安装依赖」那个，不要选"上传所有文件"。我们是零依赖，几秒就传完。
  4. 右下角提示"部署成功"即可
如果右键看不到这个菜单：说明还没开通云开发。先点工具栏的「云开发」按钮 → 开通 → 环境选 cloud1，然后再回来右键部署。
如果菜单是灰的：确认 project.config.json 里有 "cloudfunctionRoot": "cloudfunctions/"。
部署完确认一下云环境 ID 对不对：云开发控制台 → 环境 → 环境 ID， 应该和 utils/ai-config.js 里的 env 一致（现在是 cloud1-d4gmglocfb7dc5a47）。 不一致就在 ai-config.js 里改，改完重新编译。

2填 DeepSeek 的 Key3 分钟

云函数默认走的就是 DeepSeek（api.deepseek.com / deepseek-chat）， 你之前充的 10 元余额正好能用。只需要在云函数环境变量里填 Key，不用改代码。

  1. 打开 云开发控制台：tcb.cloud.tencent.com（用浏览器比开发者工具里的云朵按钮好用）
  2. 左侧 云函数 → 点 noex-ai
  3. 顶部 配置 标签 → 往下滑到 环境变量
  4. 点「编辑」→ 新增一条：
    变量名：NOEX_AI_KEY
    变量值：sk-你的DeepSeek密钥
  5. 保存。改完环境变量不用重新部署，下次调用自动生效
Key 从哪来：platform.deepseek.com 登录 → 左侧「API Keys」→ 创建 API key。 忘了的话重新创建一个旧的作废就行。
注意别用已泄露的 Key，也别把 Key 写进小程序前端代码（上传到云函数环境变量才安全）。
费用不用怕。DeepSeek 大概 1 元能聊几百轮。你充的 10 元， 按每天几十条消息算，够用几个月。影子每次回复最多 140 token，很省。

3重新编译并验证2 分钟

  1. 开发者工具点「编译」（或 Ctrl+B）
  2. 进「影子」页 → 粘贴一段聊天记录 → 开始对话
  3. 第一次回复可能要等 3～8 秒（云函数冷启动），之后就快了
成功的样子：影子说的话明显带着 TA 的味儿 —— 句子长短、口头禅、标点习惯都像，而不是统一的「嗯。」。
小白也会变：那个 cloudInit bug 修好后，小白同样走 AI 了，会比之前聪明不少。

·这次改动的技术说明

改动说明
影子改纯智能体停用本地固定句库（shadow.js 的回复池）。AI 失败时如实说明原因，绝不伪造 TA 的语气
修 cloudInit已初始化时错误地返回 false，导致除首次外全部 AI 调用失败
强化模仿TA 的原话样本 6 → 10 条、每条 40 → 60 字；system prompt 新增第 0 条铁律「第一优先级是像 TA」
错误可分类AI 失败带 code（off / not_deployed / env_bad / cloud_error / timeout / network），界面据此给可操作的提示
我的头像回右侧两页 .row.me 去掉了 row-reverse。DOM 顺序本来就是「气泡→头像」，反转后头像被甩到了气泡左边
